## Diseño

- Diseño adaptable a móvil y escritorio.
- Estética oscura con acentos cian, azul, violeta y verde inspirados en AELITYX.
- Tarjetas con estados interactivos y animaciones sutiles.
- Respeta la preferencia del sistema por movimiento reducido.
- HTML y CSS estáticos; no requiere dependencias ni proceso de compilación.

## Desarrollo local

Clona el repositorio y abre `index.html` en un navegador. Para servirlo localmente con cualquier servidor HTTP estático, usa la carpeta raíz del proyecto como directorio público.

## Despliegue

El sitio se sirve desde Vercel como una página estática. El archivo de entrada es `index.html` en la raíz y no necesita comando de build.
